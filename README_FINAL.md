# 🚀 콜드스프레이 상태 진단 AI 시스템 (최종 파이프라인 가이드)

본 문서는 전처리부터 AI 학습, 그리고 프론트엔드 대시보드(Toss 스타일 UI) 실행까지의 전체 파이프라인 실행 순서와 각 모듈의 특징을 정리한 가이드입니다.

---

## 1️⃣ 데이터 전처리 (Preprocessing)

**실행 파일:** `preprocess.py`
**목적:** 원시 오디오 파일(`.wav`)을 AI가 학습할 수 있는 2차원 이미지 형태(Mel-Spectrogram)로 변환하고 데이터를 증강합니다.

**특징:**
*   **물리적 센서 분리:** `파일명의 끝자리`를 인식하여 청진기(Stethoscope)와 마이크(Microphone) 데이터를 자동으로 분리 저장합니다.
*   **Time-window 적용:** 긴 녹음 파일을 설정한 초(Seconds) 간격(기본 2초, 1초 오버랩)으로 잘게 쪼개어 AI의 학습용 청크(Chunk)를 생성합니다. (44,100 샘플)
*   **데이터 증강(Data Augmentation):** Pitch Shifting(음정 조절) 및 White Noise 추가를 통해 절대적인 파일 개수 부족을 알고리즘적으로 보완합니다.

**실행 방법:**
```bash
python preprocess.py
```

---

## 2️⃣ AI 모델 학습 및 XAI 분석 (Training & Evaluation)

본 프로젝트는 데이터 과학의 정석을 보여주기 위해 세 가지 다른 접근법(CNN 딥러닝, Random Forest 머신러닝, AutoEncoder 비지도학습)을 모두 실험하였으며, **환경 누수(Environment Leakage)**라는 치명적인 한계를 증명해 냈습니다.

### A. Shallow CNN 모델 (Baseline & XAI)
**실행 파일:** `train_xai.py`
*   **특징:** 이미지 패턴 인식에 특화된 ResNet 계열의 가벼운 CNN 모델입니다.
*   **결과:** 엄격한 파일 단위 분리(File-level Split)를 적용했을 때 정확도 **13%**를 기록했습니다.
*   **XAI(설명 가능한 AI):** `SLIME(Sound LIME)` 알고리즘을 적용하여, AI가 판단을 내릴 때 주파수 이미지의 어느 부분(Bounding Box)을 보고 결정을 내렸는지 시각화합니다. 이 모델의 가중치(`resnet18_xai_best.pth`)가 **최종 웹 대시보드의 백엔드 엔진**으로 사용됩니다.

### B. Random Forest (Time-Split 실험 모델)
**실행 파일:** `train_rf_time_split.py`
*   **특징:** 딥러닝 대신 MFCC(음성 고유 지문)의 평균과 분산만을 이용한 강건한 트리 기반 머신러닝 모델입니다.
*   **Time-Split 실험:** 단 하나의 파일을 앞부분(Train)과 뒷부분(Test)으로 나누어 평가하는 환경 누수 실험을 진행했습니다.
*   **결과:** 99%의 압도적인 정확도를 달성했으며, 이를 통해 AI가 고장음이 아닌 '그날의 공장 배경 노이즈'를 외우는 착시 현상(Environment Leakage)을 완벽하게 증명했습니다.
*   **Feature Importance:** AI가 주목한 MFCC 주파수 대역을 막대그래프로 추출(`feature_importance.png`)합니다.

### C. AutoEncoder (비지도 이상 탐지)
**실행 파일:** `train_ae.py`
*   **특징:** 현업에서 널리 쓰이는 방식으로, 정상(Normal) 소리만 학습시킨 후 비정상 소리를 에러(Reconstruction Error)로 분류하는 모델입니다. 결과는 42% 정확도로 역시 환경을 일반화하지 못함을 증명했습니다.

## 3️⃣ 대시보드 서버 실행 (Toss UI & FastAPI Backend)

**실행 파일:** `src/api/main.py`
**목적:** 학습이 완료된 AI 모델을 얹어 실제 사용자(엔지니어)가 현장에서 사용할 수 있는 초고속 진단 웹 애플리케이션을 구동합니다.

**특징:**
*   **프리미엄 Toss 디자인 UI:** 투박한 HTML을 탈피하고, `Pretendard` 폰트, 부드러운 카드 레이아웃, `Toss Blue` 컬러 및 인터랙티브 호버 애니메이션이 적용된 최고급 프론트엔드를 제공합니다.
*   **XAI 시각화 패널:** 진단 결과뿐만 아니라, **"AI가 주파수의 어느 지점을 보고 이상을 감지했는지"**를 기준선(Golden Baseline)과 비교해주는 붉은색 바운딩 박스를 띄워줍니다.
*   **전문가 피드백 (Human-in-the-Loop):** AI의 판단이 틀렸을 경우 현장 전문가가 정답을 피드백하여 추후 모델을 고도화할 수 있는 데이터 수집 창구를 마련했습니다.

**실행 방법:**
터미널에서 아래 명령어를 실행한 후, 브라우저에서 `http://127.0.0.1:8000` 으로 접속하세요.
```bash
uvicorn src.api.main:app --reload
```

## 💡 최종 기말 발표(Defense) 핵심 요약
1. 데이터 부족 문제를 극복하기 위해 **전처리(Augmentation)**부터 최첨단 **딥러닝(CNN)**, 강건한 **머신러닝(RF)**, 현업 표준 **이상탐지(AutoEncoder)**까지 모든 수단을 동원했습니다.
2. 하지만 모든 알고리즘이 예측에 실패(13% 정확도)했으며, 이는 알고리즘 문제가 아니라 원본 파일들의 **'배경 노이즈 환경'**이 서로 너무 다르기 때문임을 **Time-Split (99% 정확도 달성)** 실험으로 완벽히 교차 검증했습니다.
3. 이를 현장에서 직접 검증하고 시각적으로 모니터링하기 위해 **XAI 기술이 탑재된 Toss 스타일의 웹 대시보드**까지 완벽하게 파이프라인을 구축했습니다.
